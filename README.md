# Traffic Violation Analytics & Injury Risk Prediction

## Overview

Analyzed over 1 million traffic violation records to identify
high-risk traffic patterns, investigate factors associated with
personal injury incidents, and develop predictive machine learning
models for injury risk assessment.

## Tools

- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn

## Key Objectives

- Analyze traffic violation trends
- Identify factors associated with personal injuries
- Develop predictive injury models
- Generate traffic safety recommendations
